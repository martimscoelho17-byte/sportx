Quando o cursor passa sobre a palavra 'Sobre', o efeito visual é o seguinte:

*   **Cor:** O texto muda de branco para um tom de **azul claro** (ciano).
*   **Transição:** A mudança ocorre de forma **suave**, com uma breve transição de desvanecimento (fade) em vez de uma mudança instantânea.
*   **Tipo de efeito:** É um **efeito de realce por cor (hover effect)**, que indica que o item é interativo.
